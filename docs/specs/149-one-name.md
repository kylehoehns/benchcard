# #149 — One name for each thing across the app

## Issue

#149. Several moments and actions in the app have two to four names, and
some of them disagree with `CONTEXT.md`. Bring each group to one term, put
that term in `CONTEXT.md`, build `planSay` from `summaryLine`, make the flow
buttons name their result, and pin the retired words with a test. Rules
named: W1, W2, W4. Parent: #153. Blocker #136 merged as #164.

## Goal

A coach reads the same word for the same thing on every screen: a break is
a break, a change is a change, a filed game is filed, a blocked plan says
what to fix, and a button says what it makes. The glossary, the copy and the
tests agree, and a test stops the old words coming back.

## Decided

From the ticket, its parent and `CONTEXT.md` (no new maintainer decisions
were needed for these):

- Moment players change: **Break** is the moment, **Change** is one player
  coming on (the count), and the verb "sub" belongs to **Sub interval** only.
  "Substitution" goes.
- Blocked plan: the panel and the Plan sheet line say "This plan can't be
  built". "Needs a fix" stays as a game pass's status, as `CONTEXT.md`
  already allows.
- Filing: "filed". The one-off new game after filing is "a new game", never
  "new day".
- Adding a game: the flow is titled "Add a game", and both ways out of it
  say "Add game" (W2 over the prototype's "Plan it" / "Use it").
- The card: "just came on", "starting five", "Card names", "Half sheet".
- Odd minutes: "odd minutes" everywhere a coach reads it.
- Season: "behind" / "ahead".
- Undo: "nine seconds", matching `UNDO_MS`.

## Constraints

- **W1.** Every new label is sentence case: "Add a game", "Add game", "Set so
  far", "Card names", "Half sheet".
- **W2.** Both ways out of Add a game name the result: "Add game".
- **W4.** Stint by stint's blocked state says what is wrong and carries the
  button that fixes it, from `blockedFix`.
- **Pure modules.** `engine.js` changes message text only, as #136 did: the
  same inputs give the same plans, codes and severities.
- **Reuse, do not re-derive.**
  - `planSay` calls `summaryLine`. One summary format.
  - The blocked title is `BLOCKED_TITLE`; the fix is `blockedFix`; the
    button comes from the timeline's panel code, not a second builder.
  - The toast strings are render.js's `ROTATION_CHANGED` and
    `SWAPS_CLEARED`.
  - The guard reads its phrases from `CONTEXT.md` through `avoidRegexes`
    (test/glossary.js), tokenizes with `jsStrings`, strips with
    `stripHtmlComments`, and lists files with `trackedFiles`. The loop that
    reads every `app/*.js` literal and `index.html` already lives in
    `test/rule-names.test.js`; move it into one helper in `test/glossary.js`
    that both tests call. Do not write a second copy of that loop.
  - The pinned words are `CONTEXT.md` text. Do not type a second list.
- **Guard.** `test/one-name.test.js` reads source, so it is built under
  `/new-guard`: plant each of three pinned words (one JS literal, one
  index.html body line, one wrapped across a line break) and watch it fail,

- **Mobile first, large text.** 390 first, then 320/32 for item 16. Do not

- **Redesign match.** Copy changes only; no layout change. Where copy

- **Precache.** Bump `VERSION` in `app/sw.js` and set `SHELL` to the digest

- American spelling. Do not quote the maintainer in code or docs.
- #146 is open and edits `state.js` near `blockedFix`. Expect a rebase

## Design

- `planSay(g, p)`: blocked → `` `${BLOCKED_TITLE}.${err ? ' ' + err.message : ''}` ``;
  otherwise compute `mins` and `subs` as today and `return summaryLine(mins,
  subs)`.
- `timeline.js`: split `timelineEmpty`'s non-roster branch into an exported
  `blockedPanel(p)` that returns the `.empty` box with title, message and
  button. `timelineEmpty` and `renderPlanTable` both call it.
- Filing, flow, card, odd minutes, season row, undo, By hand, settings
  options: string edits in place.
- app.js `#regen`: `flash(ROTATION_CHANGED + SWAPS_CLEARED)`, and
  `` `${ROTATION_CHANGED} ${summary…}` `` in `#regenLive`.
- `test/glossary.js`: add `appCopy()` returning `[file, text]` for every
  tracked `app/*.js` (literals joined) and for `app/index.html` (from
  `<body` on, `<noscript>…</noscript>` removed, HTML and `/* */` comments
  stripped). `rule-names.test.js` switches to it; its three terms still pass.
- `test/one-name.test.js`: `avoidRegexes(TERMS, DROPS, { budget:
  /\bBudget\b/ })` over `appCopy()`; fails listing `file: "phrase"`. Floors:
  at least 20 phrases parsed and at least 25 files read, so a broken parser
  or empty walk cannot pass.

# Level picks the overtime five when the coach asks for Strongest five

Status: accepted, 2026-10-28 (#369, parent #366)

Level has meant "who plays together, never how many minutes". Overtime is the
one place a coach wants to trade fairness for winning, so the Overtime sheet's
"Strongest five" puts the five highest-Level available players on the floor
for that overtime (ties to fewer minutes played). Level now decides minutes,
but only in an overtime the coach chose that for, one period at a time.

Level is still never shown: the option says "Strongest five", not a Level
word, and bench mode, the card and exports carry no Level. The other three
choices (Next rotation, Even out, Keep this five) never read Level.

Considered: a separate "closers" style list for overtime (another thing to set
up before a game, when the need is decided in the moment); using minutes
played alone (does not pick the strongest five).
